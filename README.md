# SimbioReader

SimbioReader is the official Python reader for products generated by the
Spectrometer and Imagers for MPO BepiColombo Integrated Observatory System
(SIMBIO-SYS) aboard ESA's BepiColombo mission.

The reader loads PDS4 labels and their observational arrays and tables. It
models SIMBIO-SYS metadata for STC, HRIC, and VIHI together with the Display,
Imaging, Geometry, and Reference discipline areas.

For mission information, see the
[ESA SIMBIO-SYS page](https://www.cosmos.esa.int/web/bepicolombo/simbio-sys).

## Requirements and installation

SimbioReader 1.0 requires Python 3.14.

```console
python3 -m pip install SimbioReader
```

With uv:

```console
uv add SimbioReader
```

## Python usage

Pass a PDS4 label, one of its associated data files, or a product directory:

```python
from pathlib import Path

from SimbioReader import SimbioReader

product = SimbioReader(
    Path("sim_raw_sc_stc_winx_internal_cruise_ico4b_2021-04-24_001__0_1.lblx")
)

print(product.channel)
print(product.simbio.stc.housekeeping)
print(product.imaging)
print(product.geometry)
```

The principal metadata attributes are:

- `simbio`, containing the channel-specific `stc`, `hric`, or `vihi` model;
- `display`, `imaging`, and `geometry`;
- `reference`, containing internal and external references;
- `data_arrays`, plus `image_data`, `cube_data`, and `csv_data` when present;
- `time_coordinates`, `target`, and `software_context`.

`savePreview()` is retained only as an obsolete compatibility stub. Calling it
prints a deprecation message and raises `DeprecatedMethodError`.

## Command-line interface

The package installs one command, `simbioReader`, with five subcommands:

```console
simbioReader version
simbioReader about
simbioReader phases --kind all
simbioReader filters
simbioReader filters STC --name pan-l
simbioReader info product.lblx --all
```

- `version` reports the code version and compatible PSA and SIMBIO-SYS data
  models;
- `about` reports package and author metadata;
- `phases` displays mission phases, subphases, and test campaigns;
- `filters` displays HRIC and STC filter definitions. Names are
  case-insensitive and accept forms such as `PAN-L`, `pan-l`, and `panl`;
- `info` reads a product and displays selected metadata.

With `info`, use `--hk` for instrument and CSV housekeeping tables,
`--detector` for detector metadata, `--data-structure` for observational
structures, `--filters` for the optical filter, and `--all` for every modeled
section. Units are rendered as symbols by default; `--no-symbols` preserves
the XML unit names.

Run `simbioReader --help` or `simbioReader COMMAND --help` for all options.
